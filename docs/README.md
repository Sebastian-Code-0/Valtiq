# Valtiq

Aplicación de finanzas personales multiplataforma.

## Descripción

Valtiq es una app de finanzas personales diseñada para ayudarte a llevar el control de tus ingresos, gastos y presupuestos de forma local y privada, sin depender de servicios externos.
